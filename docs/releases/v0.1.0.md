# v0.1.0 — Reproducible SWE-bench Localization Baseline

First reproducible research milestone for Efficient Agentic Inference: a frozen
SWE-bench development snapshot, inference isolated from evaluation data,
patch-derived file labels, separate prediction/evaluation programs and a CPU
lexical baseline with independent second-host reproduction.

## Pilot results

| Measure | Value |
| --- | ---: |
| Tasks / repositories | 12 / 6 |
| Recall@5 | 0.541667 |
| Strict Success@5 | 6/12 |
| Candidate recall ceiling | 1.000000 |
| Monetary cost / cost per success | unknown / unknown |

Strict Success@5 means that the top five predictions contain every file in the
reference patch's target set. It does not measure successful issue resolution.
Candidate ceiling describes the full eligible base-repository candidate corpus.

## Included

- Pinned source revisions, checksummed dev membership and reserved Verified IDs.
- Exact base-commit exports, gold-blind candidate preparation and explicit label edge cases.
- Independently executable prediction and evaluation, v2 artifact schemas and retained failures.
- Filesystem/network isolation and forbidden-field/gold mutation checks.
- Saved predictions, metrics, manifests, checksums and cross-host reproduction evidence.
- Thirty CPU contract tests and CI on Python 3.11 and 3.14.

## Evidence identity and reproduction

The release retains the original result bytes and experiment identities:
local reference code `0edd9e666bac8306f658efb1c1390b5f0f06464e`, independently
reproduced code `397df23d98d7baf634949002962bd2584628c63e`. Release preparation
updates documentation and package version metadata; the ranker, dataset, labeler,
evaluator and benchmark contract are unchanged. The package version update changes
the runtime hash of `__init__.py`; original manifests keep their original hashes.

See the [full report](https://github.com/mks-hash/efficient-agentic-inference/blob/v0.1.0/results/reports/swebench-dev-v1/README.md),
[reproduction guide](https://github.com/mks-hash/efficient-agentic-inference/blob/v0.1.0/docs/reproducibility.md)
and [original second-host run](https://github.com/mks-hash/efficient-agentic-inference/actions/runs/37379561857).
Release assets include the compact published evidence bundle, a release provenance
manifest and SHA-256 checksums. Source datasets and repository exports are rebuilt
from pinned sources rather than included in the assets.

## Scope

Development pilot only: 12 tasks from six repositories. No LLM, GPU, training,
specialization, downstream repair or final SWE-bench Verified evaluation result.
Runtime gold isolation does not establish absence of pretraining contamination.
Ranking timings exclude preparation and other system overhead; no economic gain
or broad performance claim is made.

Next planned milestone: an untuned small-model baseline on a newly frozen
development population, with explicit context coverage and resource accounting.
