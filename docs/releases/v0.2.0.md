# v0.2.0 — Untuned Small-Model Localization Baseline

Milestone notes prepared 2026-10-06. Tag and GitHub Release publication are pending.

This milestone adds the first untuned small-model comparison to Efficient Agentic
Inference: Qwen3-4B-Instruct-2507 Q4_K_M on NVIDIA L4, compared with matched-context
and full-corpus lexical controls on 60 frozen SWE-bench development tasks.

## Finding

| Treatment | Recall@5 | Strict Success@5 | Candidate ceiling |
| --- | ---: | ---: | ---: |
| Lexical, full corpus | 0.5523 | 25/60 | 0.9854 |
| Lexical, matched context | 0.2283 | 8/60 | 0.7835 |
| Untuned Qwen3-4B Q4_K_M, matched context | 0.6569 | 33/60 | 0.7835 |

All 60 model attempts are included. Eight invalid answers score as failures;
there is no training, output repair, retry or fallback. Strict success means
reference file-set coverage, not issue repair.

The primary matched-context gain is 0.4286, with repository-block bootstrap 95%
interval [0.3159, 0.5597]; the preregistered development rule passes. Full-corpus
reference gain is 0.1047, with supplementary post-run interval [-0.0012, 0.2164];
superiority to that different-evidence reference remains uncertain.

## Scope

Development data from six exposed repositories only. GPU predictions have not
been independently repeated. Model pretraining contamination, held-out
generalization, larger-generalist substitution, specialization and downstream
repair remain untested. Request latency is not total deployment latency.
Measured monetary cost and cost per successful localization remain unknown.
No efficiency or specialization claim is made.
